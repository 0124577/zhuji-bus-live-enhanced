## 5. 自测脚本

```bash
cd web && python -m http.server 8080
cd ../tests/e2e
npm install
npm run test:all
```

可用环境变量：`BASE_URL`（默认 `http://127.0.0.1:8080/`）、`CHROME_PATH`、`SHOT_DIR`（可选截图目录）。
